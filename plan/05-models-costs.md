# 05. Модели OpenAI и расходы

| Задача | Модель | Цена за 1M токенов (вход/выход), ориентир |
|---|---|---|
| Классификация комментариев, простые проверки | `gpt-5-nano` / `gpt-4.1-nano` | ~$0.05–0.10 / ~$0.40 |
| Vision: описание фото (`detail: low`) | `gpt-4o-mini` / `gpt-4.1-mini` | ~$0.15–0.40 / ~$0.60–1.60 |
| Writer (посты, истории, ответы) | `gpt-4.1-mini` / `gpt-5-mini` | ~$0.25–0.40 / ~$1.60–2.00 |
| Critic | `gpt-4.1-mini` (лучше другая модель, чем у Writer) | как выше |
| Analyst (раз в неделю) | `gpt-4.1-mini` / `gpt-5-mini` | как выше |

Цены и список моделей меняются — перед стартом сверить с openai.com/api/pricing. Имена моделей только в конфиге.

## Оценка
Пост с фото: 1 vision (кэш) + 1–3 Writer + 1–3 Critic ≈ 3–5k токенов ≈ $0.001–0.003. При 3–5 постах/день плюс ответы ≈ $0.5–2 в месяц.

## Экономия
- Structured Outputs, ограничение `max_output_tokens`
- кэш описаний фото
- prompt caching: длинная `persona.md` в начале промпта
- отладка на nano/mini, апгрейд модели только если качество не устраивает
- месячный лимит расходов в OpenAI
